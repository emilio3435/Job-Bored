Lens: Modern patterns (MP-) · Surfaces: one-flow onboarding, Pipeline board + Add-from-URL capture, dossier + Scribe tailoring, Mark-submitted confirmation, Today / Daily Brief, empty states, ⌘K · Worktree commit `f227fbb` (origin/main) · 2026-09-25

## Method

- **Research.** WebFetch/WebSearch on the public product pages, help centres, and docs of Simplify, Huntr, Teal, Linear, and Superhuman. I also used Primer for empty states, plus the specs the static-model fixes lean on: Google JobPosting JSON-LD and MDN `share_target`. Each vendor claim below cites a page I fetched. There are two exceptions:
  - tealhq.com and help.tealhq.com returned HTTP 403 to WebFetch, so Teal claims rest on its Chrome Web Store listing (fetched) or on search-result snippets, which I mark *(snippet)*.
  - Superhuman's help centre also returned 403, so its Remind-me claims are *(snippet)*. Linear's Inbox page (fetched) stands in as the confirmed source for snooze.
- **Driving JobBored.** I used the shared harness (`openApp`) in `greenfield`, `signed-in`, and `signed-in-empty` modes at `desktop` (1440×900) and `phone` (375×812). The scripts are in `/private/tmp/claude-501/-Users-emilionunezgarcia-Job-Bored/24e49a9b-ec72-4e6c-881a-2d26d8c40cbf/scratchpad/ux01/modern-patterns/`:

  - `drive1.mjs <desktop|phone>` covers Today, `?`, ⌘K, the board, and Add-from-URL with a LinkedIn URL.

  - `measure2.mjs` measures the ⌘K scroll jump and single-key triage on a focused Discovered card.
- **Running them.** Run from the worktree root: `node <scratch>/<script>.mjs [desktop|phone]`.
- **Reading code.** I read the code behind each surface: `onboarding-flow.js`, `oneflow-beat-google.js`, `oneflow-demo-board.js`, `pipeline.js`, `ingest-url-flow.js`, `role-case.js`, `scribe.js`, `scribe-score-adapter.js`, `submission-flow.js`, `flowing-writes.js`, `pipeline-transitions.js`, `today.js`, `today-data.js`, and `dawn.js`.

## Patterns to deliberately not copy

| Pattern (who) | Why not |
|---|---|
| **Auto-apply at volume**: Simplify "Autopilot" (help article title seen in search, https://help.simplify.jobs/articles/1784339-getting-started-with-autopilot; details *inferred*) | JobBored's promise is a *tailored* application. Bulk submission needs a hosted headless browser holding the user's ATS sessions, which conflicts with "no maintainer-hosted backend". It also sends untailored applications under the user's name. Out of scope. |
| **Hosted account and proprietary tracker database** (Teal, Huntr, Simplify all require sign-up) | The user's Google Sheet is the database. Every tracker feature above (MP-04, MP-07, MP-08) writes existing Pipeline columns or local IndexedDB. A JobBored account would add a server to run and a second source of truth. |
| **Chrome-only extension as the capture path** (Huntr "Chrome Job Clipper", Teal Chrome extension) | This fails "any OS, any browser" and adds a store-review and update burden. Ship the bookmarklet first (MP-02). A later optional WebExtension should reuse the same `#capture=` handoff, with no server and no new permissions beyond the active tab. |
| **Inbox/email scanning to auto-update statuses** (*inferred* for these vendors; not seen on a fetched page) | It needs Gmail read scope, a restricted Google scope with a security assessment, and it breaks Beat 1's "we ask for one permission" promise. The return-to-tab prompt (MP-04) plus Done/Snooze (MP-07) cover most of the value with Sheets scope only. |
| **Application-count goals, streaks, and paywalled AI credits** (Teal listing: "goal-setting around applications and bookmarks"; Huntr/Simplify Pro tiers) | Volume goals reward spraying over tailoring. Credit metering needs a billing backend, and JobBored is bring-your-own-key, so the provider already meters usage. |

## Top five (impact ÷ effort)

1. **MP-04 Auto-track on return (S).** A visibility listener plus prefilled source turns "remember to log it" into one tap on the step where applications most often go untracked.
2. **MP-06 Empty states that carry the action (S).** Markup only, and it rescues the stranger whose first discovery run came back empty, the most likely dead end after setup.
3. **MP-02 Static one-click clipper (M).** It is the biggest gap against Teal, Huntr, and Simplify, it unblocks LinkedIn/Indeed (the stranger's main sources), and it needs no worker because the Sheet-append path already exists.
4. **MP-07 Remind-me follow-ups (M).** It reuses existing columns and the transitions writer, and the `.ics` hand-off is the only way a follow-up reaches a user who closed the tab.
5. **MP-03 Live keyword coverage (M).** It gives free feedback during tailoring, the core job, without breaking the paid-Rescore cost rule.

MP-01 has the highest raw impact but is L effort. Rank it first if effort is no constraint.
