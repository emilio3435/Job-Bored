# UX01 audit — Settings and states

Lens: Settings and states (`SS-`) · Surfaces: Settings modal and its 7 tabs, Setup doctor, Scraper setup modal, and every empty, loading, error, and offline state in the app · Worktree: `origin/main` at `f227fbb` · Date: 2026-09-25

## Method

- Harness: `docs/programs/ux01-20260925/audit/tools/audit-harness.mjs` (`openApp`, `shoot`, `runAxe`). Runs used viewports `desktop` (1440×900) and `phone` (375×812) and modes `signed-in`, `signed-in-empty`, `signed-in-error`, and `greenfield`. v2 (`body.jb-v2`) was on for every run.
- Scripts live in `/private/tmp/claude-501/-Users-emilionunezgarcia-Job-Bored/24e49a9b-ec72-4e6c-881a-2d26d8c40cbf/scratchpad/ux01/settings-states/`. Run each one from the worktree root with `node <script> <desktop|phone>`:
  - `common.mjs`: a toast spy (a MutationObserver on `#toastContainer`) and text helpers.
  - `states.mjs`: `signed-in-empty` on the Brief tab. `signed-in-error` twice: once with the harness's gate stub, and once with the real `showSheetAccessGate` restored through a capture-phase `DOMContentLoaded` init script.
  - `states2.mjs`: the empty Pipeline tab. A mid-session 403 (a later route returns 403, then `window.loadAllData()`). Offline (`context.setOffline(true)` plus Sheets `abort("internetdisconnected")`, then `loadAllData()`). An expired token (init script sets `expiresAt` one hour in the past in both OAuth stores, then reload). Loading (Sheets routes delayed 4 s, with shots at 700 ms and 2500 ms).
  - `states3.mjs` and `states3b.mjs`: an expired token and a 403 with the real gate restored, and a 20 s wait on the expired case.
  - `offline-write.mjs`: offline with no prior refresh. It runs a stage change (Move to stage menu, then Enter) and a favorite toggle, and takes a greenfield first-paint shot.
  - `settings.mjs`: opens Settings from `#settingsBtn` and walks all 7 tabs. It records the provider default, runs Check connection with an empty key and with a fake key, opens the Clear confirm bar and cancels it, tests arrow-key focus, runs axe on `#settingsModal`, and opens Scraper setup from the Scraping tab to probe its hit-testing and `inert` state.
  - `tablist375.mjs` measures the Settings tablist geometry at 375. `contrast.mjs` reads axe's contrast data. `toasts.mjs` extracts every `showToast(` call site, 152 in total, into `toasts.tsv`.
- Code read: `settings-modal.js`, `partials/settings-modal.html`, `settings-tabs.js`, `settings-tabs.css`, `settings-tab-schema.js`, `settings-profile-tab.js`, `settings-jb-v2-tab.js`, `settings-discovery-adapters.js`, `setup-doctor.js`, `partials/scraper-setup-modal.html`, `scraper-ats-config.js`, `sheets-read-load.js`, `sheets-writeback.js`, `sheet-access-setup.js`, `auth-session.js`, `jb-v2-legacy-hide.css`, `today.js`, `dawn.js`, `welcome.js`, `pipeline.js`, `runs-tab.js`, `discovery-status-handoff.js`, `fit-profile-editor.js`, and `fit-profile-backcompat.js`.
- In-flight: `git diff origin/main...feat/greenfield-integration` for the five fenced files. Findings that PR #104 fixes carry `(fixed in #104)`.

## Top five

Ranked by impact ÷ effort.

1. **SS-01 (P0, M).** One failed refresh makes the whole pipeline look deleted, with no error and no retry. This is the single state most likely to make a stranger give up or re-create their Sheet.
2. **SS-03 (P1, S).** The Scraper setup guide opened from Settings is fully inert, and its first click closes Settings behind it. The fix is a few lines: close Settings, or exempt the modal from `inert`.
3. **SS-04 (P1, S).** On a phone, Settings exposes 1 of 7 tabs. One CSS reset (`width:auto`) gives phone users the rest of Settings.
4. **SS-11 (P1, S).** The empty pipeline has no action button in v2. Reusing Welcome's three buttons inside Dawn turns a dead end into the first step of the core job.
5. **SS-08 (P1, S).** "Nothing is waiting on you today" appears on top of error and sign-in gates. Adding one selector to the hide list stops false reassurance at the worst moment.

Next up: SS-02, the false empty state while loading (P1, M), and SS-12, the contradictory Gemini default (P1, S).
