## Top five

Ranked by impact ÷ effort.

1. **TA-04**: Applied confirm throws away what the user typed. The bug is P1 and the fix is S: pass `evidence` into the existing write. It corrupts the Sheet on every application, and the fix is one argument.
2. **TA-06**: The server-down state claims "Queued". The bug is P1 and the fix is S: gate the CTAs on reachability. This is every stranger's first click, and it currently lies to them.
3. **TA-12**: The verdict says "ready" over a QA flag. The bug is P1 and the fix is S: add a review state and show `issues[0].message`. It stops users sending documents the system already knows are flawed.
4. **TA-11**: The QA report and checklist are ready but cannot be opened. The hole is P1 and the fix is S: add an Open link for `.md` files. It is the cheapest traceability win, and v3's QA artifacts will land in the same place.
5. **TA-01 + TA-02**: Drafts use the maintainer's resume, and there is no base-resume gate. These are P0 at effort M. They carry the highest impact on the list, since every stranger gets someone else's resume, and rank fifth only because the fix is server work plus a UI gate. The UI gate alone (TA-02's "Add your resume first" block) is an S slice worth shipping first.
