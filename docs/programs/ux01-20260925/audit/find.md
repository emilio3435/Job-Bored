Answers to the kickoff questions, in short:

1. There are four real ways in: Run discovery, paste a URL, add manually, and scheduled runs. LinkedIn capture is a profile importer, not a way to add roles.
   - Only Run discovery sits above the fold.
   - Paste-URL is 2–4 screens down.
   - Manual add has no v2 entry point.
   - Paste-URL and manual-add both depend on a worker today (FD-01 to FD-03).
2. The drawer asks for 7 fields, company allow and block lists, a source preset, and a grounded-web toggle.
   - Roles, locations, remote policy, seniority and keywords are already prefilled from the onboarding fit beat (`oneflow-beat-fit.js:186-199`).
   - Fit-profile avoids are not mapped to the exclude field, the enum fields come back as free text, and the Fit-Profile banner contradicts the onboarding the user already did (FD-08, FD-26).
3. Run status:
   - Queued and running show only as a toast plus a 6 px dot on the button.
   - Lost connection, partial and failed also arrive as toasts, and those toasts leak run IDs and "worker logs".
   - The runs log labels a stopped poll "Retrying", and its status line never settles (FD-11, FD-12, FD-15, FD-16).
4. Setup leaks into the find path in the drawer's Sources and Connection tabs, the coach, the 8-step wizard, and the ingest error copy. A stranger must understand worker, webhook, tunnel, relay, secret, `.env` and npm (FD-04 to FD-07, FD-19).

## Top five (impact ÷ effort)

1. **FD-01** (P0, S): a manual fallback when URL ingest fails. It turns the only zero-setup intake from a dead end into a working path for every stranger, and the direct-append code already exists.
2. **FD-02** (P1, S): a v2 "Add manually" entry point. It restores the one intake that needs no worker, and the modal is already built and only hidden.
3. **FD-03** (P1, S): "Add job" in the top bar. It puts the zero-setup intake beside Run discovery rather than 2–4 screens down.
4. **FD-08** (P1, S): gate the Fit-Profile banner on the onboarding-saved profile. It stops sending onboarded users into a second 7-step wizard and a false "not set up" message on every drawer open.
5. **FD-05** (P1, S): preselect the recommended Tailscale path and fix its copy. The default Continue currently leads strangers down the hardest path, the one that uses ngrok and a relay.
