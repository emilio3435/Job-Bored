#113 cursor/remote-only-infer-bucket-687c
fix: accept inferred-remote listings under remote_only; add tests; improve runs Error fallback

<!-- CURSOR_AGENT_PR_BODY_BEGIN -->
What this changes
- Profile prefilter now infers remote/onsite/hybrid before applying remote_only. Listings with unset/unknown remoteBucket but clear remote signals in location/title/description are no longer hard-rejected.
- Added unit tests for prefilter inference: unknown+Remote location passes; unknown+onsite location still rejects. The onsite case test avoids the ambiguous descriptor word "distributed" in description to prevent a known false-positive remote signal from the existing inference helper.
- Small UX: when DiscoveryRuns status is partial/failure and the explicit error is blank, surface lifecycle.reasonMessage or the first warning into the Error column.

Why
- Fixes a confirmed issue where Greenhouse/other ATS listings with blank remote flags were rejected for remote_only profiles despite “Remote/Anywhere” in the location. Root cause was comparing workMode against raw remoteBucket without using the existing inference helper.

How
- profile-aware-scorer.runPreFilter now calls inferRemoteBucket({ remoteBucket, location, title, descriptionText }) from the normalizer before enforcing remote_only, and compares workMode against the inferred bucket.
- Tests extended in integrations/browser-use-discovery/tests/profile-aware-scorer-prefilter.test.ts and writer fallback covered in tests/sheets/discovery-runs-writer.test.ts.
- buildDiscoveryRunLogRowFromStatus now falls back to lifecycle.reasonMessage or first warnings[] entry for the Error cell when non-success and error is otherwise blank.

Verification
- Unit tests added for the new behavior (prefilter inference and runs Error fallback).
- Started this branch from main as requested.

Notes
- Remote-only semantics remain strict: only clearly inferred-remote passes; unknown/hybrid/onsite still reject.
- The runs Error fallback is intentionally minimal and only activates when Error would be blank.
