#110 cursor/allowlist-empty-catalog-seeds-29e7
fix(discovery): empty-catalog allowlist fallback seeds this run's companies

<!-- CURSOR_AGENT_PR_BODY_BEGIN -->
## What this changes

A post-wizard discovery run that sends a dashboard `companyAllowlist` (The Trade Desk, LiveRamp, HubSpot, …) no longer scouts with a **blank company**. Those names become ephemeral company targets for **this run only**, so Companies Seen is > 0 and grounded/ATS lanes search the companies the user actually asked for.

This is a **follow-up to draft #109**, not a replacement. #109 makes Partial-with-zeros write a concrete Error and skip Gemini scout when no Browser Use **session manager object** is injected. The remaining dogfood failure after local wizard / Tailscale is different: the catalog is empty, the allowlist is discarded, and even a correctly keyed worker searches nobody.

## Why

Local dogfood on 2026-09-16 (America/Chicago) showed Manual `worker` runs finishing **Partial** with **0 companies / 0 leads / 0 updated**. #109 correctly diagnosed the blank Error column and the “Gemini scout cooks for ~2m 42s when exploit cannot run” path.

What #109 explicitly left alone (and what still blocks a keyed run from producing leads):

1. After local wizard onboarding, stored `companies` is `[]`. Shipped ATS example seeds (Scale AI / Figma / Notion) may still sit in `atsCompanies`.
2. The dashboard already sends `companyAllowlist` + `allowUnrestrictedFallback: true` so the worker does not 400 (`companyAllowlist did not match the configured company catalog`).
3. `resolveEffectiveCompanyPools` treated that flag as “search the stored catalog.” The stored **active** list is empty, so `config.companies` stayed `[]`.
4. Grounded scout then used `{ name: "" }` (unrestricted / blank-company). `companiesSeen` is `config.companies.length` → **0**. ATS kept example seeds that do not match the user’s allowlist.
5. That is not a missing-key invention path. The names were already on the wire. We were throwing them away.

Verified in code + fixtures (no credentials claimed):

- Dashboard builder: `discovery-payload.js` sets `allowUnrestrictedFallback: true` whenever it sends an allowlist (`tests/discovery-allowlist-fallback.test.mjs`).
- Worker merge: `mergeDiscoveryConfig` → `resolveEffectiveCompanyPools`. Unknown-only + fallback previously left `companies: []` when the active list was empty.
- `createBrowserUseSessionManager` **always** returns an object (CLI or fetch fallback), so #109’s `if (groundedSearchClient && browserSessionManager)` fail-fast does not fire on the real worker. That gap stays on #109.

## How

When `allowUnrestrictedFallback` is true, the allowlist matches nothing, and the stored **active** list + history are empty:

- Seed this run’s `companies` / `atsCompanies` from the requested names.
- Keep `allowlistResolution.mode = explicit_unrestricted` so SerpApi (profile-wide) is not write-filtered away.
- Honor skip/block lists. Mixed lists (one name matches a shipped ATS seed, others do not) keep the match and add the unknown names.
- **Never persist** these names to `worker-config.json`.

Fail-closed is unchanged: omit/false still 400s as `blocked_unresolved`.

We do **not** invent companies or leads when no allowlist is sent. Roles-only payoff still relies on SerpApi / unrestricted grounded search / a Companies refresh.

## Repro (before)

1. Finish local wizard + Tailscale with a real Sheet and non-blank intent.
2. Confirm worker `companies` is `[]` (fresh `worker-config.json`).
3. Run discovery from the drawer with an AI stratum / company allowlist.
4. Discovery runs: Partial, Companies **0**, Leads **0**, ~2–3 minutes if Gemini is present.

## What Success looks like (after)

Same setup, **with keys present** (do not paste them):

- Gemini and/or SerpApi in the worker env the process actually loaded (`~/.jobbored/browser-use-discovery/.env` and/or the repo worker `.env`).
- Browser Use CLI or `BROWSER_USE_API_KEY` if you want extract beyond fetch/ATS JSON.
- **Run discovery** after applying a drawer stratum (or any path that sends `companyAllowlist`).

Expect:

- Companies Seen **= the allowlist length** (not 0).
- Leads New / Updated **> 0** when those companies have extractable first-party/ATS postings.
- If a lane is still missing, pair with **#109** so Error names Gemini / Browser Use / duration instead of a blank cell.

If the payload has **no** `companyAllowlist` (roles-only payoff): this PR does not invent names. Refresh companies in Settings → Profile, or apply an AI stratum, then run again.
