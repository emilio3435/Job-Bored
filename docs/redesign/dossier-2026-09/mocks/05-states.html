Role dossier redesign · mock 05 · every state that is not “filled”

Empty, loading, missing, broken, closed

Six states, each cropped to its top because that is where the state lives. The rule behind all of them: an absent input is an invitation, a failure names its cause and its way out, and an unverified reading says so before the reader acts on it — never a blank column, never a bare chip, never silence.

A · No role open

The shelf. Kept from production, retuned to the new type scale.

Part 03 · Waiting

Open a role to read.

Pick any card in the pipeline above. The dossier, your tailored materials and the record of everything you have done on that role unfold here.

B · Loading — the posting is being read

The verdict line says what is happening in words; the section that is waiting carries the skeleton and the live region. Nothing else is blanked, because nothing else is unknown.

C · No resume on file

There is no match data, so “You have” is an invitation with the action attached rather than an empty lane. Requirements still render, marked unknown.

D · The posting could not be read

Cause, consequence, and two ways out, in the same shape the scraper's own error payload uses (code, detail, nextStep, retryable).

E · Recovered from a bad parse

A banner above the read, not only a 7.5px chip beside a lane title. The reader is told before they act on a requirement list nobody has verified.

F · Closed — rejected

The stepper collapses to the terminal chip, the drafting actions go, and the verdict says what is still on file. The record keeps everything.
