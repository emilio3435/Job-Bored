jb-a11y demo

Manual-verification surface for the claims JB-A11Y.md lists as NEEDS BROWSER VERIFICATION. The node tests execute jb-a11y.js against a hand-rolled DOM, which records that focus() was called and that .inert was assigned — it cannot prove what a real user agent does with them. Walk this page with a keyboard and a screen reader.

Note there is no class="jb-v2" on <body>. That is deliberate: these primitives serve the legacy view too, so jb-a11y.css is unscoped.
