Privacy policy

Effective September 26, 2026. This policy describes the hosted app at https://jobbored.elioai.app. The operator is Arkansas Elio AI LLC, Little Rock, Arkansas.

What JobBored is

JobBored is a browser dashboard for a job search. The site is static. Your Google Sheet is the database. JobBored does not run an account system, and it does not keep a copy of your pipeline, resume, or Google access token on a server operated by Arkansas Elio AI LLC.

Information that stays in this browser

  • Settings you save, including a Sheet ID, an OAuth client ID, and API keys you paste, live in this browser’s localStorage, or in a config.js file you host yourself.
  • The Google access token for a signed-in session lives in sessionStorage for that tab. It is cleared when the tab closes.
  • Resumes, writing samples, preferences, and generated drafts live in this browser’s IndexedDB.

Arkansas Elio AI LLC does not receive those values. Clearing site data for this origin removes what the browser stored.

Google account data

When you choose to sign in with Google, JobBored asks for permission to:

  • See, edit, create, and delete the spreadsheets in your Google Drive that you use with JobBored, so the app can create your Pipeline sheet and read and write the rows you ask it to change.
  • See your Google account email address and basic profile, so the session can show which account is signed in.

If you start an Apps Script deploy from the app, JobBored also asks for permission to manage the Apps Script projects and deployments needed for that step. That request happens only when you start it.

The access token is used in your browser to call Google APIs for those features. The Sheet stays in your Google Drive and is owned by you. You can revoke JobBored’s access at Google Account permissions.

JobBored’s use and transfer to any other app of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.

JobBored does not sell Google user data, use it for advertising, or use it to train generalized AI models. People at Arkansas Elio AI LLC do not read the contents of your Sheet.

Data you choose to send to another service

Optional features send data only after you turn them on and supply the connection. That data is not sent to Arkansas Elio AI LLC.

  • Drafts, summaries, and scorecards go to the provider you select: OpenRouter, Google Gemini, OpenAI, Anthropic, a webhook URL you enter, or a model running on your machine. The request can include resume text, profile text, and job context from your Sheet.
  • A discovery run goes to an endpoint you configure, such as a worker on your computer, Apps Script, GitHub Actions, a Cloudflare Worker, n8n, or another URL you control. A per-run Google access token may be included so that endpoint can write your Sheet for that run. The local worker is written to drop that token from saved run state and not to log the raw token.
  • Keys you add for optional lanes, including SerpApi and Browser Use, stay in this browser until that lane calls the provider you enabled.
  • Fetching a job posting can call a scraper you run. This site does not host a scraper.

Hosting

GitHub Pages serves the static files for jobbored.elioai.app. GitHub may process ordinary request logs, such as IP address and browser type, as the host. JobBored does not add its own analytics or advertising tags.

How long information lasts

  • Sheet rows last until you change or delete them in Google Sheets.
  • Browser storage lasts until you clear site data for this origin or delete the item in the app.
  • The Google access token lasts for that browser tab’s session.

Children

JobBored is a job-search tool. It is not directed at children under 13, and it does not knowingly collect personal information from them.
